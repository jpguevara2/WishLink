# 🎁 Wishlink

Aplicación móvil orientada a la creación y gestión de listas de deseos (wishlists) personalizadas para compras o regalos en eventos especiales (cumpleaños, Navidad, Amigo Secreto, etc.).

## 🎯 Problema y Solución

* **El Problema:** Al coordinar regalos para festividades o cumpleaños, es habitual que amigos o familiares pregunten qué nos gustaría recibir. Enviar enlaces sueltos o ideas dispersas por chats genera desorden, pérdida de información y compras duplicadas.
* **La Solución:** Una aplicación móvil centralizada que permite organizar listas de regalos deseados con información detallada, alternativas de compra y una forma rápida de compartir la lista completa a través de cualquier red social o app de mensajería.

## ⚙️ Funcionalidades Clave y Casos de Uso

* **Gestión de Eventos:** Organización de artículos por ocasiones específicas (Cumpleaños, Amigo Secreto, Festividades).
* **Soporte Multi-Enlace (Hasta 2 enlaces por producto):** Permite registrar hasta 2 URLs por artículo (por ejemplo, tienda principal y alternativa con mejor precio o disponibilidad).
* **Integración Nativa para Compartir:** Botón de exportación/compartición directa compatible con las aplicaciones del dispositivo (WhatsApp, Telegram, correo, etc.).
* **Detalle de Producto:** Registro de nombre, descripción, prioridad y enlaces de compra.
